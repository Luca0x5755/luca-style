# Select one style suite per project

Each project selects either 「精緻活力」 or 「精緻專業」 as its visual baseline. Both suites share typography roles, semantic color roles, component behavior and light/dark mode rules. They differ in default accent palette, information density and component shape. A page may adjust density for its content without changing the project's style suite. Project branding may replace the default accent palette.

We considered one identical visual style for every project. It would be simpler to maintain but would erase the useful difference between approachable activity screens and quieter, denser financial interfaces. We also considered allowing a project to switch suites page by page. That would increase visual inconsistency and make shared components harder to predict.

Approachable activity and community products select 「精緻活力」. Dense financial and monitoring products select 「精緻專業」. Future projects make this choice at project setup.
