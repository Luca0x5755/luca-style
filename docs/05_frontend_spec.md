# 前端規格

## 5.1 字體與響應式字級（能力：設計系統）

字級採經網頁檢視核可的提案 A。精緻活力與精緻專業共用文字角色；資訊密度的差異由間距與排列呈現。

| 文字角色 | 電腦 | 平板 | 手機 | 字重 | 行高 |
| --- | --- | --- | --- | --- | --- |
| 介紹頁主標 | 56px / 3.5rem | 44px / 2.75rem | 32px / 2rem | 700 | 1.2 |
| 頁面標題 | 32px / 2rem | 28px / 1.75rem | 24px / 1.5rem | 700 | 1.3 |
| 區塊標題 | 24px / 1.5rem | 22px / 1.375rem | 20px / 1.25rem | 600 | 1.4 |
| 卡片標題 | 18px / 1.125rem | 18px / 1.125rem | 18px / 1.125rem | 600 | 1.5 |
| 正文 | 16px / 1rem | 16px / 1rem | 16px / 1rem | 400 | 1.75 |
| 表單、按鈕 | 16px / 1rem | 16px / 1rem | 16px / 1rem | 500 | 1.5 |
| 表格、次要文字 | 14px / 0.875rem | 14px / 0.875rem | 14px / 0.875rem | 400 | 1.6 |
| 輔助標籤 | 12px / 0.75rem | 12px / 0.75rem | 12px / 0.75rem | 500 | 1.5 |

以上 px 值以瀏覽器根字級 16px 為換算基準；實作使用 rem，行高使用無單位比例。

### 5.1.1 字體角色（能力：設計系統）

- 中文使用 Noto Sans TC，英文使用 Inter，資料數字使用 IBM Plex Mono；交付物保留必要授權資訊。
- 正文與介面文字的字體順序為 Inter、Noto Sans TC、sans-serif；資料數字為 IBM Plex Mono、monospace。
- 12px 輔助標籤只用於非主要資訊，不承擔主要閱讀或操作。

### 5.1.2 響應式規則（能力：設計系統）

- 手機：可用版面寬度小於 600px。
- 平板：可用版面寬度大於等於 600px，且小於 1024px。
- 電腦：可用版面寬度大於等於 1024px。
- 上述分類依可用版面寬度決定，不依裝置型號決定；介紹頁主標、頁面標題與區塊標題依表切換。
- 正文、操作文字與次要文字不因切換為手機版而縮小；內容透過換行與版面排列適應寬度。
- 精緻專業不以縮小共用文字角色的方式提高密度。

字級採使用者經網頁檢視核可的提案 A，數值以 §5.1 為準；可啟動正式樣張網站，在 `/foundations` 檢視各寬度的呈現。啟動方式見 [README](../README.md#開發)；頁面配置的正式來源為樣張網站。

## 5.2 路由（能力：設計系統）

| 頁面 | 路徑 | Auth | 能力 | 用途 | 頁面參考 |

| 介紹頁範本 | `/templates/intro` | 無頁面級登入要求 | 設計系統 | 檢視介紹頁的響應式範本 | 樣張網站 |

路徑相對於部署的 base path：本機開發與預覽為 `/`，GitHub Pages 為 `/luca-style/`。各路由的直接開啟與重新整理皆回應 HTTP 200；找不到頁面回應 HTTP 404。

Auth 欄指樣張應用本身的頁面要求；不改變既有私有色票與字級檢視網站的存取設定。

## 5.3 頁面與狀態（能力：設計系統）

各頁以一個主要問題及一個主要行動組織內容。四態描述頁面主內容的可用性；Success 表示正常內容呈現，不等同操作成功通知。共用元件中的操作結果通知與頁面四態分開命名。

六頁以樣張網站為頁面參考。各頁以頁面上的「樣張狀態」切換 Loading、Empty、Error、Success；檢視組合為套系（精緻活力、精緻專業）× 明暗（日間、暗黑）× 寬度（1280、834、390px），截圖基準依同一組合產生（PR-STYLE-42）。

切換狀態時保留頁面標題與導覽脈絡。Loading 不呈現誤導性的空白結論；Empty 說明尚無內容；Error 說明載入失敗並提供重試入口。

### 5.3.1 設計系統入口（能力：設計系統）→ 樣張網站 `/`

- **Story**：作為採用此系統的專案開發者，我想知道系統提供什麼，以便找到開始使用的入口。
- **Dominant region**：回答「這套系統能如何協助我的專案」；主要行動為進入設計基礎。
- **Success**：呈現雙套系介紹、交付內容及設計基礎入口；元件與範本入口為次要導覽。
- **Loading**：保留品牌與導覽，主介紹區呈現載入提示。
- **Empty**：說明介紹內容尚未提供，保留其他頁面的入口。
- **Error**：說明介紹內容無法載入，提供重試並保留導覽。

### 5.3.2 設計基礎（能力：設計系統）→ 樣張網站 `/foundations`

- **Story**：作為專案開發者，我想檢視共用視覺規則，以便在專案中一致使用。
- **Dominant region**：回答「目前套系與模式應使用哪些視覺角色」；主要行動為選擇並檢視視覺規則。
- **Success**：呈現色彩角色、字級提案 A、間距、資訊密度、元件外形與動態規則；標示語意狀態色與業務資料色的責任邊界。提供資訊密度（精簡、標準、寬鬆）與元件外形（圓潤、俐落）切換，預設為目前套系的預設值；切換只影響本頁預覽，截圖基準不含這兩個維度。
- **Loading**：保留選擇控制與章節脈絡，規則內容呈現載入提示。
- **Empty**：說明目前沒有可顯示的規則內容，保留選擇控制。
- **Error**：說明規則內容載入失敗，提供重試。

### 5.3.3 共用元件（能力：設計系統）→ 樣張網站 `/components`

- **Story**：作為專案開發者，我想檢視共用元件與狀態，以便選用符合情境的元件。
- **Dominant region**：回答「元件在目前套系與模式下如何呈現與回應」；主要行動為檢視元件。
- **Success**：呈現按鈕、表單、導覽、卡片、表格、狀態提示及載入、空白、錯誤狀態。互動元件涵蓋適用的預設、hover、focus、disabled、loading 與驗證錯誤；各狀態不強套於不適用的元件。
- **Loading**：元件展示區呈現載入提示，保留導覽與選擇控制。
- **Empty**：說明目前沒有可顯示的元件。
- **Error**：說明元件展示內容載入失敗，提供重試。

### 5.3.4 產品介面範本（能力：設計系統）→ 樣張網站 `/templates/product`

- **Story**：作為建立產品介面的開發者，我想檢視完整頁面的資訊層次，以便沿用相同規則組合元件。
- **Dominant region**：回答「如何在完整產品頁中呈現資訊與操作」；主要行動為檢視產品介面範本。
- **Success**：以導覽、頁面標題、摘要資訊、資料表格及表單展示產品介面組合；示例內容不代表三個既有專案的業務流程或 API。
- **Loading**：保留頁面框架，摘要與資料區呈現載入提示。
- **Empty**：保留資訊層次與欄位脈絡，資料區說明尚無資料。
- **Error**：資料區說明載入失敗並提供重試，不以紅綠資料值代替操作狀態。

### 5.3.5 介紹頁範本（能力：設計系統）→ 樣張網站 `/templates/intro`

- **Story**：作為建立介紹頁的開發者，我想檢視主標、說明及內容區塊的層次，以便建立一致的對外介紹畫面。
- **Dominant region**：回答「這個專案提供什麼價值」；主要行動為查看介紹內容。
- **Success**：呈現主標、正文、價值說明與主要入口；沿用介紹頁主標角色及共用元件。
- **Loading**：保留品牌與導覽，介紹主內容呈現載入提示。
- **Empty**：說明介紹內容尚未提供，保留返回入口。
- **Error**：說明介紹內容載入失敗，提供重試。

### 5.3.6 找不到頁面（能力：設計系統）→ 樣張網站（未列路徑）

- **Story**：作為打錯或點到失效網址的訪客，我想知道這個頁面不存在，以便回到樣張繼續瀏覽。
- **Dominant region**：回答「這個網址為什麼沒有內容」；主要行動為返回設計系統入口。
- **Success**：保留品牌、導覽、套系與明暗模式切換。主區塊說明找不到頁面並顯示所請求的路徑，提供返回入口的主要行動，其他頁面維持在導覽中。
- **Loading**：保留品牌與導覽，主區塊呈現載入提示。
- **Empty**：說明此處尚無可顯示的內容，保留返回入口。
- **Error**：說明頁面內容無法載入，提供重試並保留返回入口。

## 5.5 共用 OpenPencil 元件（能力：設計系統）

元件庫設計檔 `docs/mockup/luca-style-library.fig` 只含設計變數與共用元件母版，涵蓋按鈕、表單、導覽、卡片、表格與狀態提示，不含頁面 frame。變數以 `Suite`（Vibrant、Professional）、`Mode`（Light、Dark）、`Device`（Desktop、Tablet、Mobile）模式切換；母版的填色、描邊、字型、圓角與間距綁定設計變數，每個母版只有一份。

使用端的設計稿複製此檔開始，匯入專案強調色後以母版組合頁面；設計變數由程式產生，可重新匯入。

母版的 reusable 元件名稱如下，共 23 個：

| 類別 | 元件名稱 |
| --- | --- |
| 按鈕 | `C/Button/Primary`、`Secondary`、`Hover`、`Focus`、`Disabled`、`Loading`；後五項共用 `C/Button/` 前綴 |
| 輸入欄位 | `C/Field/Default`、`Focus`、`Error`、`Disabled`；後三項共用 `C/Field/` 前綴 |

### 5.5.2 元件變數（能力：設計系統）

| 角色 | 日間 | 暗黑 |
| --- | --- | --- |
| 活力成功 `success` | `#237354` | `#7ED4AB` |
| 活力警告 `warning` | `#886018` | `#EAC678` |
| 活力錯誤 `error` | `#B24445` | `#F29C96` |
| 專業成功 `success` | `#356858` | `#93C6B2` |
| 專業警告 `warning` | `#80601F` | `#DBC28B` |
| 專業錯誤 `error` | `#A34B5C` | `#DDA3B2` |
| 活力柔和強調表面 `accent-soft` | `#E3F2F0` | `#173637` |
| 專業柔和強調表面 `accent-soft` | `#EEEDF4` | `#2D2A3B` |

操作狀態色依套系調整，同套系跨專案維持一致，不供業務資料引用。活力採 V1「海岸訊號」，專業採 P1「冷杉與琥珀」（2026-10-20 使用者檢視 HTML 後確認）。成功、警告與錯誤的語意跨套系一致，搭配文字或圖示。填色主按鈕的文字在日間為白色、暗黑為炭黑。

資訊密度與元件外形的數值見 §5.4.1、§5.4.2。

互動狀態：

- 焦點框：所有元件為雙圈，內圈 2px 主要表面色、外圈 2px 主色；焦點框與背景的對比至少 3:1。
- 滑過與按下：由主色推算，色相不變；日間比主色深、暗黑比主色亮，OKLCH 明度差滑過 0.05、按下 0.10。文字與推算色的對比至少 4.5:1。
- 驗證錯誤搭配錯誤文字與錯誤色邊界。預設輸入區及選單以 `control-border` 呈現邊界，日間 `#7B8C80`、暗黑 `#65766B`；容器裝飾邊界沿用 `border`。

Select 選單：

- 選單與欄位同寬，貼齊欄位下緣，間隔 4px；圓角依元件外形（§5.4.2）；外框為 `border`，帶淡陰影，表面為主要表面。
- 選項高 40px，文字為表單文字角色。滑過項目底色為次級表面；選中項目底色為柔和強調表面並加粗，不加打勾；不可選項目為次要文字色並標示「不可選」。
- 鍵盤：Enter、Space 或方向鍵開啟；方向鍵移動；Enter 選擇並關閉；Esc 關閉不變更；關閉後焦點回到欄位。選項多於可視高度時選單內捲動。

### 5.5.3 間距與動態（能力：設計系統）

間距階梯為 4、8、12、16、24、32、48、64px，對應 `space-1`、`space-2`、`space-3`、`space-4`、`space-6`、`space-8`、`space-12`、`space-16`。套系的容器內距與區塊間距按 §5.5.2 選用。

動態時間分為回饋 120ms（`motion-feedback`）、一般切換 180ms（`motion-standard`）、區塊進出 240ms（`motion-region`）。減少動態設定下取消非必要的位移、淡入淡出與裝飾性循環動畫；載入中的意義仍由文字提示呈現。

2026-10-20 使用者確認內容載入動畫：精緻活力 V2 潮汐採 V1「潮汐波紋」，精緻專業 P3 石墨紫採 P1「方序循環」。`ContentState state="loading"` 使用套件隨附的透明背景 GIF，依套系及明暗模式切換青綠／珊瑚或石墨紫／霧藍配色。原始資產 192×192，顯示尺寸 72×72px，40 幀、20fps、2 秒循環；循環不表示實際進度。切離載入狀態即移除圖像。減少動態時改用對應靜態 PNG；保留 `role="status"`、`aria-busy` 與載入文字，裝飾動畫不重複報讀。空白與錯誤狀態不顯示動畫。

指標卡資料數字使用 IBM Plex Mono、32px、字重 600、行高 1.5，各裝置維持一致。
