在這個專案做一個「訂單管理」後台頁面。開始前先讀專案根目錄的 `README.md`。

## 功能

- 訂單列表：用表格顯示編號、客戶、金額、狀態（待付款、已付款、已出貨、已取消）、建立日期。可以用關鍵字搜尋客戶，並依狀態篩選。
- 新增與編輯：表單欄位為客戶、金額、狀態。客戶必填，金額要大於 0；不合格時在欄位旁顯示錯誤訊息。
- 刪除：刪除前要確認。
- 資料放在記憶體，用至少 8 筆假資料，不接後端。

## 四種狀態

網址參數 `state` 決定列表區的狀態，沒有參數時為 `success`：

- `/?state=loading`：載入中，一直維持載入中，不要自動切到其他狀態。
- `/?state=empty`：沒有任何訂單。
- `/?state=error`：載入失敗，要有重試的操作。
- `/?state=success`：顯示假資料。

每種狀態在畫面上可見的容器要加 `data-eval-state="<狀態>"`，例如 `<section data-eval-state="empty">`。

## 要求

- 寬度 1280、834、390 都要能用，畫面不能左右捲動。
- 符合無障礙要求，例如表單欄位要有標籤、文字對比要足夠。
- `npm run build` 要成功，輸出在 `dist/`，頁面從根路徑 `/` 開啟。
- 只能使用 `npm install <套件>`、`npm run build`、`npx tsc` 這三種指令；不要啟動開發伺服器。
- 完成並建置成功後結束，用幾句話說明做了什麼。
